About

IMDb Top 250 Scraper

Project Description

This project collects the IMDb Top 250 movies using Selenium, stores the data in CSV format, and presents it in an interactive dashboard with analytics and search tools.

Main Objective

The primary goal is to automate the collection of ranking information from IMDb and create a clean, usable dataset for exploration and analysis.

Features

  • Metadata extraction for movie rank, title, year, and IMDb rating
  • CSV export and storage
  • Dashboard summary cards
  • Search, filter, and pagination on the movies page
  • Responsive analytics charts
  • Dark and light mode themes

Technologies Used

  • Python
  • Flask
  • Selenium
  • webdriver-manager
  • Pandas
  • Chart.js
  • HTML5/CSS3/JavaScript

Workflow

  1. Open the IMDb Top 250 page using Selenium
  2. Wait for dynamic content to load
  3. Extract movie metadata using robust selectors
  4. Save results to a CSV file
  5. Load the data in Flask and visualize it in the dashboard
